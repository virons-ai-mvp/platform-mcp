# Security & Compliance Workflows

Consolidated security, compliance, and incident response workflows.

## Incident Response
- Production incidents (P0-P4 severity)
- Security incidents and breaches
- DDoS attacks and mitigation
- Service outages

## Vulnerability Management
- CVE assessment and patching
- Penetration testing
- Remediation tracking

## Compliance
- GDPR, PCI-DSS, SOC2 audits
- Regulatory filing
- Compliance reporting

## Fintech-Specific
- AML/KYC verification
- Fraud detection tuning
- Risk assessment
- ESG scoring

## Operations
- Secrets rotation
- SSL certificate renewal
- Alert configuration and investigation
- Incident postmortems
- SLO/SLI definition
