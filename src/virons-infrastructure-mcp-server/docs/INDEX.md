# Documentation

This directory contains all documentation for the Virons Infrastructure MCP Server, organized following Domain-Driven Design (DDD) principles.

## Structure

```

├── architecture/           # System architecture and design
│   ├── model-architecture.md
│   ├── comprehensive-review.md

├── compliance/            # Regulatory compliance
│   ├── overview.md
│   ├── logging-implementation.md
│   ├── policies/
│   ├── audits/
│   └── evidence/
├── operations/            # Deployment and operations
│   ├── deployment-guide.md
│   ├── deployment-complete.md
│   ├── production-deployment.md
│   ├── deployment-success.md

│   ├── implementation-progress.md
│   ├── project-complete.md

│   ├── contributing/
│   └── testing/

│   └── README.md
└── reference/             # API and reference docs
    ├── changelog.md
    └── virons-readme-template.md
```

## Documentation Principles

Following DDD architecture:

1. **Architecture** - High-level design, patterns, and decisions
2. **Compliance** - Regulatory requirements and implementations
3. **Operations** - Deployment, monitoring, and maintenance
4. **Development** - Implementation guides and progress
5. **Getting Started** - Quick start and tutorials
6. **Reference** - API docs, changelog, templates
